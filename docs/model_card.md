# RespiraTwin Risk Model Evaluation Card

> **MANDATORY CLINICAL DISCLAIMER**:
> CLINICAL ACCURACY DISCLAIMER: All event labels and outcomes are generated by a simulator. RespiraTwin does NOT claim clinical accuracy. Results measure the learning of a simulated process, not real-world clinical prediction. Intended strictly for research and proof-of-concept demonstration.

## 1. Dataset Partitioning (Patient-Level Stratified)
- **Train Split**: 210 patients, 302400 hours (Event rate: 9.21%)
- **Validation Split**: 45 patients, 64800 hours (Event rate: 8.91%)
- **Holdout Test Split**: 45 patients, 64800 hours (Event rate: 8.64%)
- **Zero Leakage**: Strict patient isolation asserted; no patient spans multiple splits.

## 2. Model Selection, Post-Hoc Calibration & Test Performance
- **Selected Architecture**: `LOGISTIC_REGRESSION` (Selected via validation set PR-AUC)
- **Near-Linear Note**: *Logistic Regression performs comparably to tree ensembles because the underlying simulator risk formulation is predominantly linear in the logit space.*
- **Post-Hoc Calibration Method**: Isotonic Regression fitted strictly on the **VALIDATION** patients (never on test data).
- **Decision Threshold Rule**: `Maximize F1 score on validation set (harmonic balance of precision and recall)`
- **Explicit Test Decision Threshold**: `0.318`

## 3. Demonstration Risk Bands & Test Observed Event Rates
Risk bands are defined on **CALIBRATED probabilities** with cutoffs chosen on the validation set.

- **Low Risk**: `Probability < 0.059 (Routine observation; demo band, not medical cutoff)`
- **Watch**: `0.059 <= Probability < 0.327 (Elevated trend; demo band, not medical cutoff)`
- **High Risk**: `Probability >= 0.327 (Simulated high-risk alert; demo band, not medical cutoff)`

### Observed Event Rates on Holdout Test Set
| Demonstration Band | Calibrated Probability Range | Test Event Rate | Monotonicity Check |
| :--- | :--- | :--- | :--- |
| **Low** | `< 0.0591` | `0.97%` | Base tier (routine monitoring) |
| **Watch** | `[0.0591, 0.3265)` | `15.76%` | Elevated tier |
| **High** | `>= 0.3265` | `53.08%` | High alert tier |

*Monotonicity Assertion*: Observed event rate satisfies `Low (0.97%) < Watch (15.76%) < High (53.08%)`.

## 4. Alert-Burden & Operational Workflow Simulation
To model alarm fatigue, consecutive alerts are merged into distinct episodes with a stated **6-hour cooldown**.

- **Cooldown Period**: `6 hours`
- **Alert Episodes per Patient-Day**: `0.0896` alerts/patient-day (242 episodes across 2700.0 patient-days)
- **Fraction of True Events Preceded within 24h**: `19.80%` (196 / 990 event episodes)
- **Median Lead Time**: `11.0 hours` prior to event onset
