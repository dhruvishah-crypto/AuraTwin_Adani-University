# RespiraTwin: Healthcare Digital Twin for Asthma Exacerbation Risk

> **IMPORTANT DISCLAIMER**: All event labels and outcomes in RespiraTwin are generated by a simulator. RespiraTwin does **not** claim clinical accuracy. Results measure the learning of a simulated process, not real-world clinical prediction. It is intended strictly for research and demonstration purposes.

## Overview
RespiraTwin is a proof-of-concept healthcare Digital Twin built for the Happiest Health Digital Twin Challenge 2026. It fuses static synthetic Electronic Health Record (EHR) profiles with dynamic environmental factors and simulated wearable time-series data to estimate the probability of a **simulated** asthma exacerbation-risk event within the next 24 hours.

## Key Features
- **Synthetic EHR Generation**: Controlled multi-variable distributions reflecting clinical correlations (age, severity, baseline vitals, comorbidities) without using real patient data.
- **Hidden Latent Truth**: Isolated ground-truth vulnerability factor strictly separated from feature pipelines to avoid data leakage.
- **Dynamic Time Series Integration**: Bundled environmental/pollution observations and simulated physiological wearable metrics.
- **Explainable Digital Twin**: Doctor-facing dashboard with risk forecasting and what-if simulation (labeled as simulated scenarios).
